# 统一工作空间与移除语言API

2026-10-25按用户要求，视频创作、项目、作品、任务、分镜、片段编辑及视频API使用同一导航；本地需求助手与后台也沿用同一框架。切换时栏目、顺序、宽度、字体、位置保持一致，仅高亮与右侧内容变化。

共用模板为 `web/workspace-sidebar.html`，维护后运行 `python scripts/build_workspace_shell.py`；`--check` 会检测任一页面偏离。样式和主题由 `workspace-shell.css/js` 统一控制，登录桥接不再临时追加菜单。作品/任务使用可直接访问的 `view` 参数；导航保留项目与镜头上下文。项目列表和新建按钮移入右侧内容，后台管理分类同样放入内容区。

外部语言助手API的HTML、JS、提供商执行模块及路由已移除，旧页面/资源/调用返回404。个人视频API（MiniMax H3、Seedance、Wan）、已有本地模型与本地需求助手保留。不删除既有项目、作品、账号或密钥数据库。
