# 成熟产品参考与本项目的取舍

参考即梦已登录页面观察到的探索、创作、资产与主体入口，以及视频生成、画布和创作分镜模板。没有调用其付费生成，也没有复制标识、素材或源码。2026年10月21日本轮重新查看了首页；资产画布的交互观察来自前一日，不能据此声称已验证即梦所有功能。

| 参考的交互原则 | 本项目的实现 | 为什么适合技术审阅 |
| --- | --- | --- |
| 创作与资产分开 | 创作表单、作品列表、任务中心，各自保留筛选与状态 | 作品是验收通过的结果，任务则包含排队、失败与取消 |
| 参数集中、可复用 | 模型规格、描述、时长和估价集中；复用只恢复表单 | 避免把切换模型或复用误当成提交、收费 |
| 项目组织素材 | 项目→剧集→分镜→多生成版本→选片→整集导出 | 剧集层级是本项目针对短剧的自主设计，没有声称即梦具有相同层级 |
| 清楚呈现素材来源 | 标注本地模型与官方云API；详情展示规格、耗时并下载生成记录 | 面试官可以追查真实运行结果，而不只看界面截图 |
| 给普通用户明确入口 | 公开示例与登录/注册，邀请码进入创作 | 当前属于邀请预览，不把共享实验室机器当成正式公有云 |

暂不复制复杂的无限画布、主体库或商业模板市场。没有参考图与人物一致性管线时，先增加角色按钮会误导使用者。优先补齐稳定推理、任务边界、数据隔离与可复现验证，再决定是否增加资产关系图。

后续值得做的改进是：独立部署与HTTPS、本人完成端到端演练、容量与故障验证，以及角色参考素材的真实模型能力。这些仍是待完成内容。
