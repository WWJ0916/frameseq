# 本地H3双卡与安装边界

## 已验证能力

两张TITAN RTX 24GB共同生成一条H3视频，固定ComfyUI0.30／FP16适配／Ulysses all-to-all序列并行。不是两个单卡任务，也不是自动合并48GB显存。输出864×480、124帧、24fps、20步，约5.17秒；新H3任务走本地，历史商业API作品保留原来源，新云生成入口已关闭。

真实成片通过完整解码、帧数/尺寸、非空白、运动与SHA检查，另看过三个真实帧；未逐帧审阅或听审音轨。SHA256：`8e239989eddeb6c93996d19208386470724f77d540b8d488fc9f49a36e9ccdbe`。采样2941.953秒，其中前向和通信249.340秒、降温2677.814秒；音视频解码63.643秒，复用既有提示词编码。没有公平的单卡/双卡完整对照，不能宣称总耗时提速倍数。

随后用普通朋友账号经临时公网HTTPS入口提交另一条新任务：202接受、重复同幂等key同ID、查询成功、Range206、完整下载SHA一致。该新视频同规格，完整生成2928.304秒；SHA256 `415f0d3840171aa0fd11d606d78c58e9dab3aabcf34636fc893f59157f7c8e31`。抽样三帧可见蓝色纸船随浅溪移动，未听审完整音轨。测试从操作者美国代理公网出口进行，不代表朋友本人网络已实测；浏览器工具超时，未完成该新视频的浏览器播放到结尾验收。临时隧道有期限，依赖网关和网络在线，不作为永久部署。

分配前检查两张允许使用的卡，持有全局和两卡锁。编码/解码用其中一张卡，采样两rank共同计算；每阶段独立报告、有界等待和异常清理，80℃监督停止，不改驱动、风扇、功耗或抢占其他任务。72℃暂停／62℃恢复是这次实验的参数，不是通用硬件建议。

## 源码与安装边界

- `h3_runtime.py`：固定profile、环境/runner配置和真实验收标记。
- `h3_local.py`：三阶段子进程、私有任务文件、锁继承、保留完整采样后只恢复解码。
- `worker.py`：双卡准入、同一队列、维护状态、进程重连与成片验证。
- `test_h3_local.py`、`test_h3_dual.py`：CPU合同/资源测试，不能替代GPU实测。

H3兼容环境、权重和独立推理runner没有放进CPU审阅包。本仓库当前提供平台执行器接口及证据，完整推理实验的通用可移植安装器仍待整理；不能只装requirements-platform就宣称能运行H3。没有runtime和匹配验收标记时拒绝任务，不静默换成Wan或商业API。
